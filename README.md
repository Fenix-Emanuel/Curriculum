# Emanuel Benitez · Portafolio

Portafolio personal de desarrollador frontend y fundador de [Ignis Studio](https://theignisstudio.com). Bilingüe EN/ES.

- **En vivo:** https://fenix-emanuel.github.io/Curriculum/
- **Versión anterior:** https://fenix-emanuel.github.io/Curriculum/v1/

## Cómo está hecho
- HTML, CSS y JavaScript puros, publicados con GitHub Pages.
- GSAP + ScrollTrigger y Lenis (`vendor/`): el nombre del hero que se abre, el manifiesto que se enciende palabra por palabra, los proyectos en fila horizontal y la línea de experiencia.
- Chispas del hero dibujadas en `<canvas>`.
- Tipografías Bricolage Grotesque, Geist y Geist Mono alojadas en `fonts/`.
- Versión sin animaciones para quien usa "reducir movimiento".

## Para editar
- Textos en inglés: `index.html`. Textos en español: objeto `ES` en `main.js`.
- Proyectos: sección `#work` en `index.html` y capturas en `img/work/`.
